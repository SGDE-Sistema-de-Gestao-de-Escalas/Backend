# SGDE - API Backend

Este repositório contém a API do Sistema de Gestão de Escalas.

## Como correr o projeto localmente:
1. Clonar o repositório
2. Correr `composer install`
3. Criar a base de dados `sgde` no MySQL
4. Configurar o ficheiro `.env`
5. Correr as migrations: `php artisan migrate`
6. Iniciar o servidor: `php artisan serve`
